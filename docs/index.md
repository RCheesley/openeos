# Empresadence documentation

Empresadence is an open source tool that helps a team run on a steady weekly rhythm.
It keeps your quarterly Priorities, weekly Actions, Blockers, numbers and Weekly Meetings in one place.
You host it yourself, and every organisation can rename the words it uses.

## How these docs are organised

- **[Tutorials](tutorials/index.md)** teach you by doing. Start here if the tool is new to you.
- **[How-to guides](how-to/index.md)** each cover one task, step by step.
- **[Reference](reference/index.md)** lists facts: roles, words, settings and commands.
- **[Explanation](explanation/index.md)** describes how the parts fit together and why.
- **[Hosting](hosting/index.md)** covers installing, deploying and upgrading.
- **[Contributing to the docs](contributing/index.md)** covers the style guide and how to add a page.

## The words on your screen may differ

Your organisation may have renamed some words. For example, a Priority may be called a Goal where you work.
These docs use the default names. The [glossary](reference/glossary.md) lists every one.
